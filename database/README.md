# 데이터베이스

후속 단계에서 ERD, MySQL 스키마 및 가상 초기 데이터를 관리할 디렉터리입니다.
현재는 SQL, 테이블 생성 스크립트 및 DB 연결 코드를 포함하지 않습니다.

- 개별 GPU, 원본 요청과 요구조건, 대안과 고객 의사, 할당 이력의 관계를 설계합니다.
- InnoDB 트랜잭션과 동시 배정 방지 제약을 검토합니다.
- 스키마 및 가상 seed SQL은 버전 관리하고, 실제 데이터·백업·덤프·접속 비밀정보는 제외합니다.
- 로컬 데이터, 백업과 덤프를 둘 경우 각각 `data/`, `backups/`, `dumps/`를 사용합니다. 이 경로는 Git에서 제외됩니다.

설계 기준은 [아키텍처](../docs/architecture.md)와 [설계 결정](../docs/decisions.md)을 따릅니다.
