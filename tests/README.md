# 테스트

후속 구현에 대한 pytest 테스트를 둘 디렉터리입니다. 현재 실행할 테스트는 없습니다.

- 단위 테스트: 가용 수량 계산, 모델·수량·동일 서버 조건 검증, 원본 보존 및 대안의 비예약 정책.
- MySQL 통합 테스트: 고객 동의 확인, 수락 시 재검증, 중복·동시 배정 방지, 전체 롤백 및 할당 해제.
- 실제 MySQL 잠금과 트랜잭션 동작은 격리된 테스트 DB에서 검증합니다.
- 실제 고객 데이터나 운영 DB를 사용하지 않습니다.

상세 검증 시나리오는 [요구사항](../docs/requirements.md)의 검증 기준을 따릅니다.
